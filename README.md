# 天堂2M 模擬器 v2.1

- 以 v2.0 為基礎，保留傳說／神話測試召喚、八組召喚機率與546筆卡片資料。
- 原有合成欄位外觀不變，在合成等級最後新增「超越神話 → 唯一」。
- 職業唯一目標：波那伊特；壺精唯一目標：吉爾塔斯。尚未設定材料與機率，合成按鈕停用。
- 移除獨立的唯一合成研究導覽頁，統一放入卡片合成。
- 最大合成每次最多11次，保留逐次顯示所有成功與失敗返還卡片。
- 保底次數可超過20次，領取一次扣20次，六組計數器各自獨立。
- 使用者遊戲截圖名錄採同階級等權分配，非官方個別機率。
- 本版程式語法與ZIP完整性檢查通過；未執行完整瀏覽器測試。

## 啟動
解壓縮後以Chrome或Edge開啟 `index.html`。如曾匯入自訂資料庫，請注意設定頁「恢復內建資料」會清除進度，操作前先匯出備份。


## v2.2 更新
- 職業唯一「波那伊特」及壺精唯一「吉爾塔斯」均可合成：消耗3張超越神話卡，成功率10%。
- 失敗時3張超越神話材料全部消耗，不返還；成功時亦消耗材料，獲得1張唯一。
- 唯一合成不納入20次保底。一般合成一次，最大合成單次最多11次，逐次消耗材料。
- 最大合成結果同名卡合併顯示「本次獲得 ×N」，不顯示背包持有量。
- 超越神話失敗時，另外顯示保留的神話卡片「保留 ×N次」，不計入本次取得。
- 合成機率及材料規則依使用者指定，並非本次獨立驗證之官方機率。

## v2.3 製作頁面
- 左側新增「製作」，採用使用者選定的三欄式版面。
- 三種神話技能書選擇箱成功率依序為7%、7%、3.5%；成功率加成0%、大成功率0%。
- 標題下方只顯示「成功機率 X% ↑0%、大成功機率0%」，不顯示失敗機率。
- 左側與中央使用使用者提供的原始圖片（assets/craft-chest-small.png、assets/craft-chest-large.png）。
- 材料條件、限制尚未設定，製作按鈕停用；可切換箱子、調整預計製作數量。
- 保留 v2.2 召喚、收藏、合成、保底等功能。

## v2.4 合成材料顯示
合成頁面的材料區，同一張卡片只顯示一個方框，標示「持有 N 張」。收藏、結果區與抽卡顯示不變；合成引擎的材料扣除及機率不變。

## v2.5 商城

- 財貨商品（圖片取自使用者上傳的遊戲截圖，裁切原始商品圖）：130鑽石 TWD100；440鑽石 TWD330；1240鑽石 TWD930；2040鑽石 TWD1530；4000鑽石 TWD2990。
- 保留原始圖片外觀；裁切後的圖片置於 `assets/diamond-*.png`。

- 此版本保留原有抽卡、合成、收藏及製作功能。

## v2.6 商城模擬購買與統計
- 商城標題右側顯示目前鑽石餘額。
- 五種財貨商品啟用「購買」按鈕；點擊後確認並**模擬**獲得對應鑽石。
- 每筆模擬購買累計其標示 TWD 價格至「統計紀錄」的「累計模擬消費 TWD」。
- 購買資料（鑽石、累計模擬 TWD、最近1000筆紀錄）存於瀏覽器本機進度，隨匯出/匯入與重設一併處理。
- **沒有串接付款、信用卡或真實鑽石系統，不會實際收費。**
- 製作材料商品與消耗鑽石功能仍待設定。

## v2.7：財貨 → 材料 → 製作連動
- 保留原本五種鑽石商品及模擬 TWD 消費累計。
- 製作材料商城新增太古氣息箱 1 個（100 鑽石，取得 4 個創造氣息）、太古氣息箱 11 個（1,000 鑽石，取得 44 個創造氣息）。
- 製作材料商城圖片裁切自使用者提供的遊戲截圖，保留商品外觀。
- 購買時驗證鑽石餘額，扣除鑽石並立即增加創造氣息；製作頁與商城共用本機材料庫存。
- 三種神話技能書選擇箱，每次均消耗 3,840 個創造氣息；成功率依序 7%、7%、3.5%。成功與失敗都消耗材料；成功獲得一個對應的模擬製作成品並計入製作紀錄，尚未設定開箱內容。
- 本機進度匯出、匯入及重設沿用原系統。統計紀錄增加創造氣息、製作次數與製作成功次數。
- 此專案僅模擬消費與製作，不進行真實付款。

## v2.8 — 製作材料批次購買視窗
- 點擊製作材料商品的「購買」後，彈出黑底金字數量選擇視窗。
- 可選擇 1、5、10 次，或輸入任意正整數次數。
- 自動計算鑽石消耗、創造氣息取得量與剩餘鑽石。
- 餘額不足、非正整數、超出安全數值範圍時不可確認。
- 確認後一次扣除鑽石、增加共用創造氣息庫存，並寫入本機購買紀錄。
- 財貨模擬購買、三種神話技能書製作、抽卡、合成與保底系統保留。
- 無真實付款功能。

## v2.9 製作介面與弧光石
- 參照使用者提供的遊戲畫面，製作頁面改為左側清單、中央原始寶箱圖片、右側創造氣息與弧光石投入控制、底部製作操作。
- 三箱基本成功率依序為7%、7%、3.5%；弧光石單顆加成為3.5、3.5、1.5個百分點；最多投入27、3、6顆。
- 第一箱投入27顆時顯示加成94.5%，加總101.5%，實際抽樣機率限制為100%。
- 三箱每次製作均消耗3,840個創造氣息。製作失敗獲得1顆弧光石；成功不獲得。
- 弧光石由三箱共用庫存；投入的弧光石無論成功或失敗均消耗。批次製作的投入量為「每次」投入量。
- 模擬購買鑽石改為直接購買、不再二次確認；製作材料批次購買仍保留彈窗。
- 尚未設定製作帳號與伺服器數量限制；製作成品暫存於 craftRewards，尚未開啟箱內獎勵。
- 所有資料保留在瀏覽器本機進度；不涉及實際付款。

## v3.3 製作音效與讀條同步
- 點擊製作立即播放 `assets/sounds/craft-start.mp3`（約3.024秒）。
- 進度條的動畫時長由音效的 duration 設定；音效資訊尚未就緒時使用3.024秒預設值。
- 動畫完成時播放 `assets/sounds/craft-complete.mp3`（約1.52秒），同時開啟未揭曉結果視窗。
- 單次製作維持大型卡片；批次製作維持小型卡片，可逐張點擊或全部揭曉。
- 避免連續製作時沿用上一輪進度條狀態；若瀏覽器限制音效播放，製作流程仍可繼續。

- 檢查：JavaScript 語法與 ZIP 完整性；尚未進行完整瀏覽器互動與音訊同步實測。

## v3.4 製作結果揭曉音效
- 玩家點擊尚未揭曉的製作結果時，成功播放 `assets/sounds/craft-success.mp3`（約1.08秒），失敗播放 `assets/sounds/craft-failure.mp3`（約0.91秒）。
- 「全部揭曉」仍一次顯示所有結果，僅播放一段代表性結果音效，避免多個聲音同時重疊。
- 已揭曉的卡片再次點擊不會重播音效，也不會重複結算獎勵。
- 保留原本的開始製作約3秒音效、同步進度條、讀條完成音效及既有製作規則。
- 音效來源為使用者提供的影片裁切音訊。
